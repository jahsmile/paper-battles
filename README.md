# Бумажные бои

Браузерная игра, в которой герои — это детские рисунки, сфотографированные с бумаги. Героев расставляют на листе на две стороны, и они дерутся сами.

## Запуск

Откройте `index.html` в браузере или выложите папку на любой статический хостинг (подойдёт GitHub Pages). Сборка и сервер не нужны.

## Что есть в игре

- 11 встроенных героев из рисунков, у каждого свои атаки, характер, реплики и суперудар.
- Свои герои из фото: вырезание с ручной правкой и увеличением, затем разметка точки выстрела и подвижных частей.
- Настройка героя: сила, скорость, до трёх атак, характер, движение, реплики, свой звук атаки.
- Режимы: свободный бой, игра на двоих с тайной расстановкой, турнир из десяти уровней.
- Приёмы игрока в бою (клякса, ластик, скрепка), пауза, ускорение, повтор финала.
- Арены: город, космос, лес или своя из фото.

## Где хранятся данные

Свои герои, настройки и расстановки лежат в `localStorage` браузера. Сохранение в аккаунт и передача героя по коду работают только когда игра открыта как артефакт Claude (через `window.claude`); в обычном браузере игра работает без них.

## Как устроен код

- `index.html` — собранная игра, один файл.
- `assets/` — рисунки встроенных героев.
- `src/template.html` — разметка и стили.
- `src/game.js` — герои, бой, отрисовка, окна вырезания и настройки.
- `src/extras.js` — хранение, режимы, меню, повтор, музыка, редактор частей, арены, звуки.
- `src/cutout.js` — вырезание рисунка из фото.
- `src/manifest.json` — размеры рисунков встроенных героев.
- `build.py` — собирает `index.html` из `src/`: `python3 build.py`.
- `tools/` — скрипты, которыми рисунки вырезались из исходных фото (пути в них относятся к рабочей среде, нужны только как справка).

Исходные фотографии рисунков в репозиторий не входят.

## Локализация

Исходники остаются на русском. `build.py` при сборке оборачивает русские строки в `T(...)`, собирает ключи и вшивает переводы из `src/i18n/<код>.json` (карта «русская строка → перевод»).

- Языки: ru, en, es, pt, fr, de, it, nl, pl, uk, tr, ar, ur, hi, bn, id, vi, th, zh, ja, ko.
- Язык берётся из настроек браузера, сменить можно в «Меню» → «Язык».
- `python3 build.py --keys` обновляет `src/i18n/keys.json` — список строк, которые нужно перевести.
- Строка без перевода показывается по-английски, а если нет и его — по-русски.

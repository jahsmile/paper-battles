# Паспорт героя

Паспорт — файл `meta/<id>.json` в ветке `gallery`, где `<id>` совпадает с именем файла героя в `heroes/`. Игра находит его сама: у автора героя показывает церемонию «Настоящий паспорт», у остальных применяет молча.

Паспорта пишутся только для рисунков. Для фотографий людей паспорт не делается, такой герой убирается из галереи.

```json
{
  "v": 1,
  "el": "fire | ice | steel",
  "cool": 1,
  "kind": {"ru": "Ледяная ведьма", "en": "Ice witch"},
  "note": {"ru": "Одна-две фразы о том, что видно на рисунке.", "en": "…"},
  "chr": "ключ из CHR в src/game.js",
  "atks": ["до трёх ключей из ATK, первый главный"],
  "idle": "ключ из MOVES",
  "muz": [0.5, 0.3],
  "at": [0.4, 0.5],
  "parts": [{"poly": [[0.1, 0.3], [0.3, 0.3], [0.3, 0.6]], "pv": [0.3, 0.35], "anim": "ключ из PARTANIM", "a0": -40, "a1": 40, "amp": 1}],
  "lines": {"ru": {"start": "…", "kill": "…", "low": "…", "win": "…"}, "en": {"start": "…", "kill": "…", "low": "…", "win": "…"}}
}
```

- Координаты — доли ширины и высоты рисунка, от 0 до 1. `muz` — откуда стреляет, `at` — где пила или главный удар, `pv` — где часть крепится к телу.
- `cool` — от 1 до 5. Рисунок решает, какой герой, а не насколько он сильный: сила на старте у всех почти одна.
- Реплики — короткие, детские, без грубостей; несколько вариантов через `/`.
- Частей не больше четырёх; если у героя автор уже разметил части сам, паспорт их не трогает.
